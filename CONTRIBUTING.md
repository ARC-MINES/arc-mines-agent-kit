# Contributing

Include a concrete failure or interaction your change improves. Update the
relevant skill or reference and add a runnable regression check when behavior
changes. Keep examples free of third-party runtime dependencies.

Run `npm test` and `npm run demo`. For UI guidance, report the viewport, input
method, reduced-motion setting, and network condition you actually checked.
Screenshots from a different implementation do not verify the live game.

Use Conventional Commits, for example `fix(reveal): reject mismatched retries`.
Describe what changed and the checks performed. Avoid speculative roadmap
content, copied game assets, and unsupported adoption or audit claims.
